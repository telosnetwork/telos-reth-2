# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting](https://github.com/telosnetwork/telos-reth-2/security/advisories/new)
to send the maintainers a confidential report.

Include the affected commit or release, impact, reproduction steps, and any suggested mitigation.
Please avoid accessing other users' data, disrupting public services, or publishing details before
a coordinated fix is available.

## Supported versions

Security fixes are made against the latest Telos release line. Until the first production release
is promoted, builds from this repository are development candidates and are not supported for
public production traffic.

This fork includes both upstream Reth and Telos-specific code. Report an issue here when it affects
the Telos binary, its deployment, or the Telos integration boundary; maintainers will coordinate an
upstream disclosure when appropriate.
